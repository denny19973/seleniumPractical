# Selenium + Pytest<br>

## 專案簡介<br>

使用 Python 搭配 Selenium 與 Pytest，針對電商網站進行 UI 自動化測試，並整合 Allure 產出測試報告。

## 測試內容<br>

- 使用者登入（成功 / 失敗）
- 商品加入購物車
- 購物車內容驗證
- 結帳流程

---

## 技術使用<br>

- Python
- Selenium
- Pytest
- Allure Report
