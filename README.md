# Selenium + Pytest

## 專案簡介

使用 Python 搭配 Selenium 與 Pytest，針對電商網站進行 UI 自動化測試，並整合 Allure 產出測試報告。

## 技術使用

- Python
- Selenium
- Pytest
- Allure Report
